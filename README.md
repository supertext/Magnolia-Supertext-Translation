# Supertext Translation for Magnolia

Translate Magnolia pages into the other languages of their site with [Supertext](https://www.supertext.com) AI translation.

- **Translate with Supertext**: an action in the Pages app (page list and page editor) translates a page, its areas and components, and optionally its subpages, into the languages you tick. Existing translations are kept unless you choose to overwrite them.
- Translates every text and rich text field marked `i18n: true` in the page's and components' dialogs, composite fields included. Formatting and links stay intact. Translations are saved in the page's language versions (`title_de_CH` …), ready to review in the page editor and publish.
- **Export for translation / Import translation**: two more actions in the Pages app download a page's texts as an XLIFF 1.2 or HTML file for a translator, a translation tool or Supertext's web app, and import the translated file.
- **Supertext** app (app launcher → Translation): API key with an automatic check, endpoint, form of address, language codes (with a table of how each site language is sent), excluded and additional fields, version information for Supertext support.

Requires Magnolia 6.4 (Community Edition or DX Core, Java 17/21) and a Supertext API key. No Supertext account yet? [Create one at supertext.com](https://www.supertext.com/person/en/account/signin). Generate your API key at [supertext.com → Integrations → API](https://www.supertext.com/en/integrations/api) (requires the Admin role).

## Export for translation and import (XLIFF and HTML)

Besides translating with Supertext AI, you can export a page with its components as a file, have it translated elsewhere and import the result.

- **Where:** the *Export for translation* and *Import translation* actions in the Pages app, next to *Translate with Supertext*.
- **Formats:** XLIFF 1.2 for translation tools such as Trados, memoQ or Phrase (formatting travels as protected tags; several target languages in one file), or HTML (one language per file) for translators or Supertext's web app, which keeps the file's head and `data-st-id` attributes, so the translated file imports as it is.
- **Import:** the file says what it was exported from and for which language. The translations are written with the same rules as a Supertext AI translation, and a summary shows what was imported and what was skipped: source changed since the export (import those anyway with *Also import texts whose source changed since the export*), not translated, formatting changed, not in the file.
- **Safe:** files over 10 MB, files from another system and translations that add markup the source doesn't have are refused; uploaded files aren't stored.

Details: [user guide](docs/USER_GUIDE.md#export-for-translation-and-import-a-translated-file).
